# Track: npm Package Split (Core vs. Full)

This track focuses on decoupling the content extraction logic from the semantic classification engine. This allows for a lightweight core package suitable for cross-platform integration (e.g., providing a structural markdown signal to a native Swift/Foundations classifier on iOS/Mac).
