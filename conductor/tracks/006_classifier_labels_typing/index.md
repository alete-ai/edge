# Track 006: Classifier Labels Typing

## Overview
This track adds explicit, statically-typed definitions for the classifier output labels in both TypeScript and Swift codebases. Currently, labels are returned as generic `String`/`string` types, which requires consumers to guess or manually look up the categories.
